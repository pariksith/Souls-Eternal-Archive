# Souls Eternal Archive

Souls Eternal Archive is a modern, minimalist journaling application designed to preserve thoughts, memories, and reflections as timeless digital artifacts. The project emphasizes a calm, immersive writing experience with an offline-first, privacy-focused architecture.

---

## Overview

Souls Eternal Archive reimagines personal journaling by combining mindful design with modern web technologies. All entries are stored locally, ensuring privacy, reliability, and uninterrupted access without requiring a backend or user accounts.

---

## Features

- Distraction-free, elegant user interface  
- Offline-first local storage using IndexedDB  
- Progressive Web App (PWA) support  
- Fast, lightweight, and performance-optimized  
- Privacy-centric: no server-side data storage  

---

## Tech Stack

- Vite  
- TypeScript  
- Tailwind CSS  
- IndexedDB  
- Client-side PWA architecture

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation

```bash
git clone https://github.com/pariksith/Souls-Eternal-Archive.git
cd Souls-Eternal-Archive
npm install

Run in Development
npm run dev

Build for Production
npm run build

Usage

Create and manage journal entries directly in the browser

All entries are saved automatically to local storage

Install as a PWA for a native-like journaling experience
